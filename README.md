# Structural Integrity & Fatigue/Fracture Analysis Toolkit

Interactive engineering application for fatigue and fracture mechanics analysis developed in Python.

This tool implements classical durability and damage tolerance models used in aerospace structural life prediction.

## Features

- Stress–strain visualization
- S–N fatigue life prediction
- Strain-life analysis (Coffin–Manson)
- Crack growth simulation
  - Paris Law
  - Walker Model
  - Forman Model
- Stress intensity factor analysis
- Fracture mechanics safety diagrams
- Reliability Monte Carlo simulation
- Mean stress fatigue diagrams
- Variable amplitude fatigue
  - Rainflow cycle counting
  - Miner’s rule damage accumulation
- Automatic engineering report generation

## Technologies

- Python
- Streamlit
- NumPy
- Matplotlib
- Rainflow counting

## Running the Application

Install dependencies:

pip install -r requirements.txt

Run app:

streamlit run app.py
